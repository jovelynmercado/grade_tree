## What Was Built

A comprehensive student grade management system with Binary Search Tree visualization called "GradeTree".

### Features
- Role-based authentication (admin/student)
- Admin dashboard with statistics
- Student CRUD management with subject enrollment
- Subject CRUD management
- Assessment CRUD with categories (quiz, exam, project, assignment) and weights
- Grid-based grade entry with auto-save
- BST visualizer with SVG rendering (insert, search, traversals)
- Analytics charts using Recharts
- Student dashboard to view personal grades
